Plan Prompt Template

A fill-in-the-blank prompt for turning requirements into a plan that both a human and an agent can follow.

How to use it

1. Copy everything from PART 1 to the end of the file.
2. Replace every [FILL: ...] with your details. Delete a section's content (not the heading) if it doesn't apply, or write N/A.
3. Paste it to the agent. It will ask questions one at a time if something blocks the design, then produce the plan.
